# Security

If you find a vulnerability in this repository or on the hosted servers, please don't open a public issue. Write to **info@webnova360.com** with the subject "Tremulous security" and a short description of how to reproduce it. We answer within a few days.

Please don't run load tests or denial-of-service attempts against the live servers; they share a host with other services.

Out of scope: bugs in the original game logic (wallhacks, exploits inside a match) – those are fun to report as normal issues.
